# VoicePingAutoReconnect

BetterDiscord плагин для мониторинга пинга голосовых каналов, автоматического переподключения при скачках задержки (5000 ms) и тестирования соединения.

## Возможности
- **Мониторинг пинга:** отслеживание задержки соединения голосовых сессий в реальном времени.
- **Авто-реконнект (5000ms):** при зависании соединения (пинг 5000 мс) плагин автоматически перезаходит в канал без участия пользователя.
- **Кнопка тестирования:** в меню статистики соединения (зелёные полосочки) добавлена кнопка «⚡ Вызвать 5 000 ms пинга» для мгновенной проверки функции реконнекта.

## Установка
1. Скачайте `VoicePingAutoReconnect.plugin.js`.
2. Поместите файл в папку плагинов BetterDiscord:
   - В Discord: **Настройки пользователя** ➔ **Плагины** ➔ **Открыть папку плагинов**.
3. Включите плагин в списке.
