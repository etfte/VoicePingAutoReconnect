# VoicePingAutoReconnect v2.3.0

Продвинутый плагин для BetterDiscord, который замеряет **реальный сетевой пинг** голосовых каналов и тиммейтов, рассчитывает **Ping Diff команды**, отправляет карточку связи в чат в 1 клик, оптимизирует регионы серверов и автоматически спасает от зависания соединения (**баг 5000ms**) в Discord.

---

## ✨ Основные возможности v2.3.0

1. **👥 Индикатор связи тиммейтов (Teammate Ping):**
   - Рядом с ником каждого участника в голосовом канале отображается его персональный пинг (`🟢 38ms`, `🟡 85ms`, `🔴 190ms`).
   - Сразу видно, у кого именно проблемы со связью — у вас или у собеседника.

2. **⚖️ Ping Diff (Разница задержек команды):**
   - Показывает разницу между вашим пингом и пингом тиммейтов (`+25ms` или `-10ms`).
   - В модальном окне смены региона `🌐` выводится сводная таблица команды, помогающая выбрать сервер, идеальный для всей пати, а не только для одного игрока.

3. **📢 Voice Ping Share (Отправка статистики в 1 клик):**
   - Нажмите иконку `📢` в панели звонка, и плагин автоматически отправит красивое Markdown-сообщение со статистикой текущего канала (название, регион сервера, пинг, потеря пакетов, число участников) прямо в чат!

4. **🌐 Смена и оптимизация региона сервера (Smart Region Switcher):**
   - Иконка `🌐` открывает меню выбора сервера (Frankfurt, Rotterdam, Finland, Stockholm, Warsaw, Madrid, Russia и т.д.) с отображением пинга для каждого региона и авто-рекомендацией лучшего.

5. **⚡ Реальный замер задержки (RTT & WebRTC):**
   - Честный опрос WebRTC сессии Discord и измерение сетевого RTT до шлюза без фейковых генераторов.

6. **📶 Отображение пинга по требованию (30 секунд):**
   - Кнопка в правом верхнем тулбаре Discord включает показ пинга каналов ровно на 30 секунд с плавным авто-скрытием.

7. **🔄 Авто-реконнект при спайках (Watchdog 5000ms):**
   - Сторожевой алгоритм мониторит соединение и моментально перезаходит в канал при зависании (баг 5000ms).

8. **⚡ Честный тест 5000ms:**
   - Кнопка `⚡` эмулирует спайк для проверки реакции детектора.

---

## 🚀 Установка

1. Скачайте [`VoicePingAutoReconnect.plugin.js`](./VoicePingAutoReconnect.plugin.js).
2. Поместите в папку BetterDiscord:
   - Discord: **Настройки пользователя** ➔ **Плагины** ➔ **Открыть папку плагинов** (`%APPDATA%\BetterDiscord\plugins`).
3. Включите плагин в списке.
4. Перезагрузите Discord нажатием **`Ctrl + R`**.
