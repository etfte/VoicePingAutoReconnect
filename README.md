# VoicePingAutoReconnect v2.1.0

Продвинутый плагин для BetterDiscord, который замеряет **реальный сетевой пинг** голосовых каналов, оптимизирует RTC-регионы серверов в 1 клик, позволяет отображать задержку по кнопке на 30 секунд и автоматически спасает от зависания соединения (**баг 5000ms**) в Discord.

---

## ✨ Основные возможности

1. **🌐 Смена и оптимизация региона сервера (Smart Region Switcher):**
   - Если пинг в канале высокий, администраторы и модераторы могут нажать на иконку глобуса `🌐` прямо в панели звонка.
   - Открывается удобное модальное окно с выбором любого голосового сервера (Frankfurt, Rotterdam, Finland, Stockholm, Warsaw, Madrid, Russia и т.д.) со сменой региона для всех участников в 1 клик.

2. **⚡ Реальный замер задержки (RTT & WebRTC):**
   - Для активного канала считывает точные метрики задержки из живой WebRTC-сессии Discord (`RTCConnectionStore`).
   - Для остальных каналов производит измерение Round Trip Time до сетевых шлюзов Discord через ваше подключение / VPN / прокси.

3. **📶 Отображение пинга по требованию (30 секунд):**
   - По умолчанию список каналов чист и не перегружен.
   - По клику на нативную иконку в правом верхнем тулбаре задержка отображается ровно на 30 секунд с плавным авто-скрытием и таймером обратного отсчета.

4. **🔄 Авто-реконнект при спайках (Watchdog 5000ms):**
   - Сторожевой процесс непрерывно мониторит состояние связи.
   - При зависании WebRTC-пакетов или скачке задержки выше установленного порога (по умолчанию 4500–5000 мс) плагин за доли секунды бесшовно перезаходит в текущий канал, моментально возвращая звук.

5. **⚡ Кнопка честной симуляции 5000ms:**
   - Кнопка `⚡` тестирует именно сторожевой алгоритм: подменяет показания датчика на 5240ms, чтобы вы могли лично убедиться в срабатывании порога без выдергивания сетевого провода.

6. **🎨 Нативный интерфейс Discord:**
   - Кнопка активации размещена в правом верхнем тулбаре Discord (рядом с поиском и закрепами).
   - Микро-иконки быстрого управления (`🌐`, `📶`, `⚡`, `🔄`) встроены в панель звонка перед кнопкой отключения (0 лишней высоты).

---

## 🚀 Установка

1. Скачайте файл [`VoicePingAutoReconnect.plugin.js`](./VoicePingAutoReconnect.plugin.js).
2. Поместите его в папку плагинов BetterDiscord:
   - В Discord: **Настройки пользователя** ➔ **Плагины** ➔ **Открыть папку плагинов** (`%APPDATA%\BetterDiscord\plugins`).
3. Включите плагин `VoicePingAutoReconnect` переключателем в списке.
4. Перезагрузите Discord нажатием **`Ctrl + R`**.

---

## ⚙️ Настройки
В настройках плагина внутри BetterDiscord можно настроить:
- **Порог пинга:** значение в миллисекундах, при котором запускается перезаход (по умолчанию: `4500`).
- **Длительность показа:** сколько секунд держать бейджи видимыми по кнопке (по умолчанию: `30`).
